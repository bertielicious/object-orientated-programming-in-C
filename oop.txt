What is OOP?

OOP organises software around objects.

An object contains:

Data (variables)
Behaviour (functions that operate on that data)

Think of a real-world object:

Light Bulb

Data:

On/Off state
Brightness

Behaviour:

Turn On
Turn Off
Set Brightness

In OOP we bundle these together.

OOP Pillars

The four major OOP concepts are:

Encapsulation
Abstraction
Inheritance
Polymorphism

Let's build them one at a time using C.

1. Encapsulation

Encapsulation means:

Keep data and functions together.

Traditional C (not OOP style)
C

}

Everything is global.

Problems:

No protection
Difficult to manage

#include <stdio.h>
#include <stdbool.h>

typedef struct
{
    bool is_on;
    int brightness;
}
LightBulb;

/*
    Turn the bulb ON.
*/
void LightBulb_turnOn(LightBulb *bulb)
{
    bulb->is_on = true;
}

/*
    Turn bulb OFF.
*/
void LightBulb_turnOff(LightBulb *bulb)
{
    bulb->is_on = false;
}

/*
    Print bulb information.
*/
void LightBulb_print(const LightBulb *bulb)
{
    if (bulb->is_on)
    {
        printf("State = ON\n");
    }
    else
    {
        printf("State = OFF\n");
    }

    printf("Brightness = %d\n",
           bulb->brightness);
}

int main(void)
{
    /*
        Create a bulb object.
    */
    LightBulb kitchenBulb;

    kitchenBulb.is_on = false;
    kitchenBulb.brightness = 75;

    LightBulb_turnOn(&kitchenBulb);

    LightBulb_print(&kitchenBulb);

    return 0;
}
//Output:
State = ON
Brightness = 75
